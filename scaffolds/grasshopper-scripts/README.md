# Grasshopper Scripts

Open-source Grasshopper/Rhino scripts for computational design workflows, plus practical examples and documentation.

## Who this is for
- Architects and designers automating repetitive Grasshopper workflows.
- Fabrication teams creating parametric tooling.
- Teams who need custom Rhino/Grasshopper scripting support.

## Repository structure
```text
scripts/
  geometry/
  data-trees/
  optimization/
  fabrication/
examples/
  panelization-demo/
  facade-grid-demo/
docs/
assets/
```

## Getting started
1. Clone this repository.
2. Open files in Rhino + Grasshopper.
3. Read `docs/getting-started.md` for conventions and setup notes.

## Featured scripts
- `scripts/geometry/` - geometry utility scripts.
- `scripts/data-trees/` - data tree helpers and converters.
- `scripts/optimization/` - optimization workflow helpers.
- `scripts/fabrication/` - fabrication and export utility scripts.
