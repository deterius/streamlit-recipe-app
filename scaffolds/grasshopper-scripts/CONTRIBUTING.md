# Contributing

Thanks for your interest in contributing.

## Development flow
1. Open an issue describing the bug/feature.
2. Create a branch from `main`.
3. Keep pull requests focused and small.
4. Include before/after screenshots for visual Grasshopper changes.

## Commit style
Use conventional-style messages where possible:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
