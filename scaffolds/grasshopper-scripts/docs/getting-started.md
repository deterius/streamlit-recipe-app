# Getting Started

## Requirements
- Rhino 7 or Rhino 8
- Grasshopper
- Optional plugins documented per example

## Conventions
- Keep one script/tool per subfolder in `scripts/`
- Add a short `README.md` inside each script folder describing:
  - Inputs
  - Outputs
  - Rhino/Grasshopper version
  - Dependencies

## Recommended first steps
1. Open `examples/panelization-demo`.
2. Review `scripts/geometry` helpers.
3. Try modifying one parameter and save a versioned update.
